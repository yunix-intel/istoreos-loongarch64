## 关键发现与修正

1. **Karakeep PDF 默认关闭**：`CRAWLER_STORE_PDF` 默认 `false`，日志会写
   `Skipping storing the PDF as it's empty`。这不是失败；设 `true` 后 Wikipedia PDF
   落盘 649,933B，截图 211,990B，HTML 277,148B。
2. **LBrowser 嵌入可行但不能公开分发**：embedded 1.49GB，比 runtime 1.03GB 多约
   370MB；Playwright/Patchright 全过。deb 无明确 LICENSE/copyright，镜像不能推送。
3. **wg-easy 的真实握手已补验**：之前只验证到 302/DB；本轮用两个容器（均
   `NET_ADMIN`）在默认 bridge 上完成双向 handshake，client transfer 92B received /
   276B sent，server 276B received / 92B sent。
4. **Linkwarden 三 tag 同 digest**：`loong64`、`24.10-la5`、`2.16.3` 均为
   `sha256:23cb706f…466e`；上游 tag 指向 `474dd11`，实际构建 commit 为 `952ac454`
   （仅 mobile 变更，服务端代码一致）。
5. **CasaOS 格式化 API 路径语义**：POST 必须传整盘 `/dev/sda`，传 `/dev/sda1`
   返回成功但不挂载；旧 NBD 记录仍残留，与本次 SATA 无关。
