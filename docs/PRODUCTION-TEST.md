# 生产级全量测试计划（开发完成后执行）

## 触发条件

- 应用镜像池开发收口（当前目标：商店清单 + 计划内应用全部上架）
- 固件与 CasaOS 功能开发冻结
- 有一台**专用**龙芯验证机（独占磁盘与网络，可重启）

## 范围

1. **42+ 应用镜像**：逐个做业务级验证
2. **固件 laN**：U 盘/真机首启、overlay、docker/podman、dockerman、商店安装
3. **CasaOS**：systemd 安装、local-storage 磁盘（识别/挂载/卸载/SMART/重启自挂）、应用商店安装
4. **稳定性**：关键服务 24h 运行、重启恢复、数据持久化

## 测试环境
- 龙芯 3A6000（或同级），Loongnix/Debian
- 开放版权测试数据：音乐（Jamendo/Free Music Archive）、视频（Blender 开放电影）、电子书（Project Gutenberg）、PDF 样本
- 外部服务：PostgreSQL（jellystat/miniflux）、索引器/下载器（sonarr/radarr 链路）
- 独立网络，避免污染生产

## 单应用验证清单（模板）
1. 拉取镜像 → 启动（记录启动时间/日志）
2. 首页/健康检查 200
3. 完成首次配置（管理员、数据库、路径）
4. 真实业务操作（上传/扫描/播放/下载/同步）
5. 重启容器 → 数据仍在、配置未丢
6. 升级到新 tag → 数据迁移正常
7. 资源占用（CPU/内存）与日志健康
8. 记录 bug 与限制，形成结论

## 验收与分级
- **A（生产可用）**：清单 1–8 全过
- **B（可用但有已知限制）**：核心业务过，限制写清
- **C（实验）**：仅冒烟，不建议生产

## 输出
- `docs/TEST-REPORT.md`：逐应用结论 + 证据
- `docs/IMAGES.md`：补充验证等级列
- 修复项回流镜像/固件，重新发版
